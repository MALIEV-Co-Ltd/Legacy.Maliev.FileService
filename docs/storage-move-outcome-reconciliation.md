# Storage move outcome reconciliation

During scanned `POST /Uploads` promotion, the service can return an outcome-unknown `503` when a GCS copy or source deletion may have committed but its response was lost, canceled, or incomplete. The service deliberately retains the private quarantine object and any copied destination; it does not create clean `Upload` metadata or issue a signed URL for an unconfirmed promotion. Do not blindly replay the request or delete either object by name.

For `POST /Uploads`, the warning log records only the `operationId`. Use that identifier inside an access-controlled operator session to locate the quarantine prefix (`{QuarantinePrefix}/{operationId:N}/`) and correlate the durable idempotency checkpoint, if one exists. Inspect GCS object metadata and generations and the `Upload` metadata record read-only. Record the operation ID, checkpoint state, whether each expected generation exists, and the reconciliation decision. Object names can contain customer filenames: keep them within the controlled storage/database session and out of tickets, chat, and routine logs.

If clean metadata is absent, leave the checkpoint unknown and both storage locations private until an authorized operator establishes which generation is the scanned source, whether the copied destination exists, and whether either deletion committed. A `503` is not proof that a copy failed. Do not mark the workflow complete, issue a URL, or run a time-based/destructive cleaner solely because an object lacks metadata. Escalate uncertain ownership or generation changes rather than deleting a possibly newer object.

Current limitation: automatic `ReconcileUploadAsync` requires both persisted clean metadata and a matching destination size. A move interrupted before metadata insertion cannot self-complete from the retained objects, and an unkeyed request has no durable replay checkpoint. Track these retained private objects for explicit operator disposition; this note does not authorize a production storage or database change.
